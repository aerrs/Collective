# Collective

Multi-clan Discord integration for OSRS clans running on Collective Bot.

Sends clan chat, drops, level-ups, personal bests, deaths, bingo submissions, and event attendance to your clan's Discord via webhooks. Also adds local-only features: rank icons, chat highlighting, @mention notifications, and a clan chat log.

## Install

Available from the RuneLite Plugin Hub. Search "Collective".

## Configure

Get your webhook URLs from your clan's Discord with `/plugin-setup` (requires Collective Bot). Paste them into the plugin's config sections — each feature has its own webhook field so you can route drops, chat, and events to different channels.

Everything is opt-in and default-off. Nothing leaves your client until you enable a feature and provide a webhook.

## Features

- Clan chat relay to Discord
- Loot / valuable drops feed
- Level-ups, PBs, combat achievements, quests, collection log, pets
- Deaths (with HCIM tag-loss mode)
- Bingo tile auto-submission
- Event attendance heartbeat
- Rank icons in the local chatbox
- Chat highlighting and @mention notifications
- Local chat log (saved to disk)
